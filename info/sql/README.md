# Fondamenti SQL

Il percorso [Fondamenti SQL](fondamenti-sql/README.md) insegna a leggere e modificare dati direttamente in MariaDB: `SELECT`, `INSERT`, `UPDATE`, `DELETE` e una relazione 1:n. Si può svolgere indipendentemente dagli esercizi API.

Il database di prova è `school_lab`. La cartella contiene `schema.sql` per crearlo e `cleanup.sql` per eliminarlo.
