# Informatica

I materiali sono organizzati per argomento:

- [SQL](sql/README.md): introduzione al linguaggio e percorsi DDL, DML e DQL con sintassi MySQL. Il DDL contiene 12 esercizi progressivi basati su casi reali; resta disponibile anche il laboratorio introduttivo MariaDB.
- [API](API/README.md): PHP, HTTP e accesso al database.

Si può iniziare dalla guida SQL oppure dal primo esercizio API. I singoli README spiegano preparazione, obiettivo e comandi.
