# Gestione progetto

Questa sezione raccoglie esercizi di economia, economia aziendale e project management. La programmazione è uno strumento per applicare i concetti della materia.

- [Valutazione di un'azienda con il reddito medio prospettico](valutazione-azienda/README.md): dai redditi e dalle imposte di cinque anni alla previsione dei redditi futuri e a una stima del valore aziendale. Si svolge in TypeScript e comprende test che guidano il lavoro.
