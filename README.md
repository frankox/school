# Eserciziario scolastico

Questo repository raccoglie esercizi pensati per gli studenti, suddivisi per materia e classe.

## Struttura del repository

Si parte dalla materia, si sceglie la propria classe e infine si raggiunge l'esercizio. Gli esercizi possono essere raggruppati anche per argomento.

```text
school/
└── info/                         # materia
    └── quinta/                   # classe
        └── sql/                  # argomento
            └── 01-csv-to-sql-api/ # esercizio
                └── README.md
```

Per iniziare:

1. apri la cartella della materia, ad esempio [Informatica](info/README.md);
2. scegli la tua classe;
3. scegli l'argomento e poi l'esercizio;
4. leggi il `README.md` presente nella cartella dell'esercizio.

Ogni esercizio ha un proprio README con l'obiettivo, i requisiti, le istruzioni di setup e i comandi necessari per avviarlo o verificarlo.
